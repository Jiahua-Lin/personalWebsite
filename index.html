I learnt HTML through All Star Code, and I'm not going to lie, this was probably the easiest coding language I've ever touched upon (kind of got the gist of it within 2-3 days). I think HTML is one of the most fun languagues that I've learnt so far because of how it literally structures the skeleton of your website. Like HTML, it's very easy to learn, but CSS can get really messy really fast (I almost always use CMD F to find whatever id or class I'm searching for). Other than that though, I really enjoy what CSS can do, (I especially love how easy it is to animate elements) and I'm coming to learn what else it can still do. But, because it's kind of hard to work with when your website becomes complex, I give it a 5/10.

Python was a language I had self-taught myself. Using Pycharm and Pygame, I created some several small games that were relatively simple; these games were mainly to help me get more familiar with the language. After taking a break and getting familiar enough, I decided on creating a game that had a similar game mechanic like Angry Birds Epic. The game is still in development and I'm at the upgrading development stage now. Python is kind of like JavaScript to me but a little easier, so I give Python an 8/10.

Lua was the first coding language I touched upon, and while it's really easy and simple by itself, when put in a game engine like Roblox's, it gets pretty difficult. I've been on and off when it comes to coding Lua on Roblox; because of how many different events, services, and classes there are on Roblox, it gets really confusing really fast. I've spent a lot of time on this language on Roblox, and quite frankly, I still find it hard to code. I have created a good amount of games with Roblox Lua, however (showcased in coding experience) and I am proud of these games, but because of the difficulty, I give it a 3/10.

Snap! was the coding language used for my AP Computer Science Principles class; it's a really easy programming language to use (HTML is arguably easier in my opinion) and while it's block-based, it can get really complex really fast with the amount of libraries and extensions they offer. For my create project, I created a code-heavy survival game program that took up more than 5 MB (the max is 10 MB. I found that out the hard way), and I'm really proud of it because I spent a lot of time and effort working on this program (and would add more if it weren't for the size limit). I give Snap! a 10/10 because the concepts were easy to work with and I'm kind of like, not going to lie, a professional in that language :D.
